Introduction Flex Container Flex Items Justify Content Align Items Flex Wrap
Introduction

Flexbox is a one-dimensional layout method in CSS designed to arrange items in rows or columns within a container.

It makes it easier to design flexible responsive layout structures without using float or positioning.

To use flexbox, you simply set the display property of a container element to flex.

display: flex;
Flex Container

The flex container is the parent element on which display: flex is applied.

All direct children of a flex container automatically become flex items.

The flex container establishes a new flex formatting context for its contents.

  • Set with display: flex or display: inline-flex
  • Controls the main axis with flex-direction
Flex Items

Flex items are the direct children of a flex container.

Each flex item can grow, shrink, or maintain its size based on the available space in the container.

Individual flex items can be controlled using the flex-grow, flex-shrink, and flex-basis properties.

  • Can use the order property to change display order
  • Can use align-self to override container alignment
Justify Content

The justify-content property aligns flex items along the main axis of the container.

Common values include flex-start, flex-end, center, space-between, and space-around.

This property is essential for controlling horizontal spacing when the flex direction is set to row.

  • center centers items along the main axis
  • space-between distributes items evenly with no leading or trailing space
Align Items

The align-items property aligns flex items along the cross axis of the container.

This is especially useful for vertically centering content when the flex direction is set to row.

Common values include stretch, flex-start, flex-end, and center.

Flex Wrap

The flex-wrap property controls whether flex items are forced onto a single line or can wrap onto multiple lines.

By default, flex items will all try to fit onto one line, which can cause them to shrink.

Setting flex-wrap: wrap allows items to flow onto new lines as needed.

  • nowrap is the default value
  • wrap-reverse wraps items in reverse order
